Import data

Paste cells copied from Excel, Google Sheets or a CSV / tab-separated file. The current table is replaced.

How to use

  • Edit: click a cell and type. Tab / Shift+Tab moves sideways, Enter moves down. Pressing Tab in the last cell adds a row.
  • Select: drag across cells, or Shift+click. Click a row number or column letter to select the whole row or column.
  • Merge: select a block, then press Merge (Ctrl+M). Horizontal merges become \multicolumn and vertical merges become \multirow.
  • Column alignment: type in the small box above each column: l, c, r, p{3cm}, S (siunitx), etc.
  • Header rows: the first n rows are the header. booktabs puts \midrule after them.
  • Math: write $\alpha$ or $10^{-3}$. Text inside $…$ is never escaped.
  • Paste from Excel: paste a block of copied cells into any cell, and it fills the grid from there.
  • Convert: the LaTeX updates live. With live update off, press Convert (Ctrl+Enter).
  • Your work is saved in this browser automatically.
